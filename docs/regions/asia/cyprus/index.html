Cyprus

Asia · in-country and expert open sources

Published

August 24, 2026

Open-source reporting and expert sources for Cyprus, indexed for analysts: independent outlets (Cyprus Mail, Politis) alongside official data bodies and, where relevant, state media flagged for framing. This is a starter set of 4 sources — it can be deepened on request.

data = FileAttachment("../../../data/sources.csv").csv({typed: true})
country = data.filter(d => d.country === "Cyprus")

All Cyprus sources

viewof topicSel = Inputs.select(["All", ...Array.from(new Set(country.map(d => d.topic)))], {label: "Topic", value: "All"})
viewof channelSel = Inputs.select(["All","Website","Social media"], {label: "Channel", value: "All"})
viewof q = Inputs.text({label: "Search", placeholder: "name, type, note…", width: 280})
viewof sortBy = Inputs.select(new Map([
  ["Composite ↓","composite"], ["Accuracy ↓","accuracy"], ["Uniqueness ↓","uniqueness"],
  ["Timeliness ↓","timeliness"], ["Transparency ↓","transparency"], ["Verifiability ↓","verifiability"],
  ["Accessibility ↓","accessibility"], ["Depth ↓","depth"], ["Name A–Z","name"]
]), {label: "Sort by", value: "composite"})
filtered = {
  let rows = country;
  if (topicSel !== "All") rows = rows.filter(d => d.topic === topicSel);
  if (channelSel !== "All") rows = rows.filter(d => d.channel === channelSel);
  if (q) { const s = q.toLowerCase();
    rows = rows.filter(d => (d.name+" "+d.source_type+" "+d.notes+" "+d.perspective+" "+d.platform).toLowerCase().includes(s)); }
  return rows.slice().sort((a,b) => sortBy === "name"
    ? (a.name < b.name ? -1 : a.name > b.name ? 1 : 0) : (b[sortBy]-a[sortBy]));
}
function scoreBadge(v){ return html`<span class="score score-${Math.round(v)}">${v}</span>`; }
function compBadge(v){ return html`<span class="score composite score-${Math.round(v)}">${v}</span>`; }
function pillClass(p){ return p.startsWith("Independent") ? "pill-indep" : p.startsWith("Pro-") ? "pill-prowar" : "pill-state"; }
function srcCell(d){ return html`<td><a href="${d.url}" target="_blank" rel="noopener" class="src-name">${d.name}</a>
  <span class="pill ${pillClass(d.perspective)}">${d.perspective}</span>${d.channel==="Social media" ? html`<span class="pill pill-social">${d.platform}</span>` : ""}${d.is_dataset==="yes" ? html`<span class="pill pill-dataset">dataset</span>` : ""}
  <span class="src-note">${d.notes}</span></td>`; }
function scoreCells(d){ return html`${[d.accuracy,d.uniqueness,d.timeliness,d.transparency,d.verifiability,d.accessibility,d.depth].map(v=>html`<td class="num">${scoreBadge(v)}</td>`)}<td class="num">${compBadge(d.composite)}</td>`; }
html`<div class="osal-scroll"><table class="osal">
  <thead><tr><th>Source</th><th>Topic</th>
    <th class="num" title="Accuracy">Acc</th><th class="num" title="Uniqueness">Uni</th>
    <th class="num" title="Timeliness">Tim</th><th class="num" title="Transparency & bias disclosure">Tra</th>
    <th class="num" title="Verifiability">Ver</th><th class="num" title="Accessibility">Acs</th>
    <th class="num" title="Analytical depth">Dep</th><th class="num" title="Composite — mean of the seven">Comp</th>
  </tr></thead>
  <tbody>${filtered.map(d => html`<tr>${srcCell(d)}<td>${d.topic}</td>${scoreCells(d)}</tr>`)}</tbody>
</table></div>`
NoteReading the scores

Seven criteria scored 1–5; composite is their mean. Accuracy, Uniqueness, Timeliness, Transparency/bias, Verifiability, Acs = accessibility, Depth. Perspective labels are disclosure, not quality; the gold dataset tag marks quantitative sources (see Datasets). This is a starter set for Cyprus — it can be deepened on request. See the Methodology.
